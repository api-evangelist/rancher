Rancher redesigned its Workloads Dashboard to restore a global resource overview that had been removed for performance reasons. The new interface runs on an optimized API and provides high-level health metrics plus drill-down by workload type and namespace, with advanced filtering and deep linking so users can isolate errors and share specific views with teammates.
